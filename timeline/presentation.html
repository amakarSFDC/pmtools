How to produce a visual Gantt chart from a spreadsheet
in under two minutes — every week.

What the tool does

📄 Read a CSV

You maintain one CSV file listing projects, milestones, and dates. That's the only file you ever touch.

⚙️ Run one command

A single Python script reads the CSV and generates a fully self-contained HTML Gantt chart.

🌐 Open in any browser

The output is a plain .html file — no server, no login, no install. Share it like a document.

💡 Each weekly run creates a new dated file (e.g. timeline_2026-W30.html). Old snapshots are never overwritten — you always have a history.

Prerequisites

🐍 Python 3.9 or later

Check your version in a terminal:

python3 --version

If not installed, download from python.org.

🌐 Internet connection

The chart loads the Frappe Gantt library from a CDN when you open it in a browser. No extra Python packages needed.

✅ No pip install required. The script uses only Python's standard library.

Installing Python (if needed)

🍎 macOS

  1. Open Terminal (Spotlight → type "Terminal")
  2. Run python3 --version — if it prints a version, you're done
  3. If not, go to python.org/downloads and click Download Python 3.x.x
  4. Open the downloaded .pkg file and follow the installer
  5. Verify: open a new Terminal and run python3 --version

🪟 Windows

  1. Open Command Prompt (Start → type "cmd")
  2. Run python --version — if it prints a version, you're done
  3. If not, go to python.org/downloads and click Download Python 3.x.x
  4. Run the installer — check "Add Python to PATH" on the first screen
  5. Verify: open a new Command Prompt and run python --version
⚠️ Windows users: use python instead of python3 in all commands shown in this guide. Make sure Add Python to PATH is checked during install — without it the python command won't be found.
💡 Any Python 3.9 or later works. As of 2026 the current release is 3.13 — download whichever is shown as the latest stable version on python.org.

Installing Python via Homebrew Recommended at Salesforce

1
Check if Homebrew is already installed: 
brew --version

If you see a version number, skip to step 3.

2
If Homebrew is not installed, install it: 
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/master/install.sh)"

This runs the official Homebrew installer. Follow the prompts — it may ask for your Mac password.

3
Install Python: 
brew install python

Homebrew installs the latest stable Python 3 and keeps it up to date with brew upgrade python.

4
Verify the installation: 
python3 --version
💡 Homebrew is a Mac-only package manager. These steps do not apply to Windows — see the previous slide for Windows installation.

Step 1

Prepare your project data

1The CSV columns

Column What it means Example Rules
project_name The top-level project or workstream. Groups milestones together and assigns a color. Website Redesign Up to 3 distinct colors; extras cycle.
milestone_name Name of the individual task or milestone shown on the chart bar. Design Mockups Any text.
start_date When this milestone begins. 2026-07-15 Must be YYYY-MM-DD.
end_date When it ends. Set equal to start_date to mark a point-in-time milestone (diamond). 2026-08-04 Must be ≥ start_date.
⚠️ Keep the header row exactly as shown. Dates as MM/DD/YYYY or other formats will break the chart.

1Sample CSV — milestones vs. bars

project_name,milestone_name,start_date,end_date
Website Redesign,Discovery & Requirements,2026-07-01,2026-07-14   # bar
Website Redesign,Design Mockups,2026-07-15,2026-08-04          # bar
Website Redesign,Development,2026-08-05,2026-09-15             # bar
Website Redesign,Go-Live,2026-09-15,2026-09-15               # diamond ← same date

Mobile App Launch,Architecture & Setup,2026-07-01,2026-07-21   # bar
Mobile App Launch,Feature Development,2026-07-22,2026-09-01    # bar
Mobile App Launch,Go-Live,2026-09-15,2026-09-15               # diamond

Bar  Duration task

start_date ≠ end_date → renders as a colored horizontal bar spanning the date range.

◆  Point-in-time milestone

start_date = end_date → renders as a colored diamond marker at that date.

Step 4

The weekly update routine

4Weekly update — 5-minute routine

1

Open data/projects.csv in Excel, Google Sheets, or a text editor.

2

Update dates or add new milestones as the program progresses. Add new rows for new tasks; update end_date if a milestone slips.

3

Save the file, return to your terminal, and run:

python3 generate_timeline.py
✅ Each run writes a new file named by ISO week. Running twice in the same week overwrites only that week's file — all older snapshots remain in output/.

Advanced options

A
Generate a chart for a specific past or future week: 
python3 generate_timeline.py --week 2026-07-14

Pass the Monday of the target week. Useful for back-filling or previewing a future snapshot.

B
Use a different CSV file: 
python3 generate_timeline.py --csv /path/to/other/projects.csv

Point the script at a different data file — useful if you manage multiple programs.

C
Combine both flags: 
python3 generate_timeline.py --csv other.csv --week 2026-08-11

Troubleshooting

!
"Error: CSV not found"

Make sure you are running the script from the timeline/ directory and that data/projects.csv exists.

!
Chart is blank / Frappe Gantt doesn't load

You need an internet connection — the chart library loads from a CDN. Check your network and reload.

!
Dates look wrong on the chart

Verify all CSV dates are in YYYY-MM-DD format (not MM/DD/YYYY). Confirm every end_date ≥ start_date.

!
Export PNG shows a blank or partial chart

Scroll back to the chart start, then export. If the issue persists, try Chrome or Edge — some browsers restrict canvas-based export.
